# Responsive Portfolio (2022)

My first responsive personal portfolio website built with **Next.js 13** and **TypeScript** to showcase early frontend projects and skills.

> Current portfolio: [gorkemalpaslan.com.tr](https://www.gorkemalpaslan.com.tr)

## Tech Stack
- **Next.js 13** & **React 18**
- **TypeScript**
- **Material UI (`@mui/material`)** & **EmailJS**

## Getting Started
```bash
git clone https://github.com/gorkemAlpaslan/Responsive-Portfolio.git
cd Responsive-Portfolio
npm install
npm run dev
```
